## **Descrição:** 
Nesta atividade, adicionamos um segundo LED ao circuito e usamos um botão para controlar os dois. A cada aperto do botão, os LEDs mudam de estado seguindo uma sequência: primeiro acende o LED 1, depois ele apaga e o LED 2 acende, no terceiro aperto os dois ficam apagados e, no quarto, o LED 1 acende novamente, reiniciando o ciclo.
